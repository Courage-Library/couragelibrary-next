# Permanent gates

Every code phase must pass these before it is committed. Phase-specific suites are added on top. Run them against a local production build; never against production.

**Live gates run ONLY through the runner** (`docs/testing/LIVE_GATES.md`): `npm run build`, then `node scripts/live/with-server.cjs --port=3100 -- "<gate 1>" "<gate 2>" …` — free-port check, health confirmed (≤ 120 s) before any gate, ≤ 15 min per gate, server always stopped. No hand-started servers or unbounded wait loops.
