Rules for the final set

  • Brand icons = core loop onlyHome, Learn, Practice, Mocks, Today's mock, Current Affairs, Results, Mistake Vault, Memory Lock. Everything else uses standard icons styled to match.
  • Logo colours only when activeIdle icons are slate. Cyan → violet appears only on the active item (and the Today's mock button), never as decoration.
  • Three sizes drawn16 (simplified), 20/24 (standard), 32+ (cards, empty states). Each checked by eye at its size.
  • Delivered as codeSVG masters + one React icon component with a name map; no icon font, no images, works in dark mode later.
  • AccessibleIcons are decorative next to labels (aria-hidden); icon-only buttons carry aria-label + tooltip.
  • No emoji, no stock icons for core featuresOne family, one meaning per icon, everywhere.
