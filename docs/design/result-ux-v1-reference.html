Result page: what changes

The page should answer four questions in order: How did I do? · Am I improving? · What should I do next? · Where exactly did I go wrong? Numbered pins match the list below. Question data stays as it is; only layout and experience change.

Today

  • Score, then sections, then a long history table, then questions
  • One "What to do next" tip
  • Right/wrong shown mainly by colour
  • 4–5 different action links on every question
  • Long scroll with no way to jump

Proposed

  • Score + change vs last attempt + trend at the top
  • 3 next steps + weak topics right below
  • "Your answer" / "Correct answer" labels
  • One main Learn button + 3 small icon actions
  • Jump bar, review filters, history collapsed at the bottom

Changes

Approved 23 Nov 2026. No emoji anywhere in the UI: line icons (SVG) only. All presentation only. Uses data the result already has (answers, topics, time, past attempts).

  1. 1
    Jump barSticky chips: Summary · Next steps · Weak topics · Sections · Review · Past attempts. Re-attempt always one click away.
  2. 2
    Score + change vs last attemptBig clean score "82.5 / 200", ▲/▼ chip vs last attempt of the same mock, one-line plain verdict.
  3. 3
    Five clear tilesCorrect · Wrong with negative marks · "Skipped · 0 marks" · Accuracy · Time used. No confusing "% of maximum" line.
  4. 4
    Trend chart in %Only the same mock type (no mixing 50- and 200-mark tests). Rank/percentile slot shown as "coming" until data is enough.
  5. 5
    3 next stepsLearn the weakest topic · practise the slowest topic · revise mistakes. Each has one button.
  6. 6
    Weak topicsLowest-accuracy topics with Learn + Practise. Too little data → "Answer more questions to see weak topics".
  7. 7
    Sections with paceScore, accuracy, time for every section, and time per question with "on pace / too slow" (text, not only colour).
  8. 8
    Review filtersWrong / Skipped / Correct / All with counts, plus a section filter. Opens on "Wrong" by default.
  9. 9
    Text labels on options"✕ Your answer" and "✓ Correct answer" — readable without colour. Wrong uses coral, correct uses green.
  10. 10
    One "Explanation" labelSame block for wrong, skipped and correct questions.
  11. 11
    One main action"Learn: <topic>" button + 3 icon buttons (Mistake Vault, Memory Lock, Report) with labels/tooltips. "Next wrong ›" to move fast.
  12. 12
    Past attempts collapsedMoved to the bottom, closed by default, same mock type only.
  13. 13
    Phone jump chipsHorizontal scroll chips instead of a long scroll.
  14. 14
    Phone bottom barRe-attempt + "Review 27 mistakes" always reachable with the thumb.
  15. 15
    Phone review modeOne question per screen, Prev / Next wrong, filter chips at the top, explanation and Learn button in view.
