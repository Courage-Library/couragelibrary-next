# AI Authoring Architecture Specification
**Authoritative Research-First External AI Authoring Pipeline & Verification Boundary**

---

## 1. Executive Summary & Purpose

The **AI Authoring Subsystem** powers Courage Library's content and examination intelligence generation.

Unlike naive LLM integrations that treat AI as a direct content generator with publication authority, Courage Library treats external AI as an **untrusted research and drafting agent** operating within a strict human-in-the-loop copy-paste contract (`CL-EXAM-AUTHOR-v1.0`).

The system requires **zero paid AI API dependencies** and works identically across Claude, ChatGPT, Gemini, Perplexity, and DeepSeek.

## 2. The 12 Sacred Research Pillars

Every prompt generated by `ExamKnowledgePromptBuilder` enforces 12 non-negotiable architectural pillars:

1. **Research Mandate (`CONTEXT ≠ TRUTH`)**: Context provides structural boundaries and current system state, but factual claims must be independently investigated from authoritative primary sources.
2. **4-Tier Source Authority Hierarchy**:
   - **Tier 1 (Primary Authoritative)**: Official recruiting authority, official notification PDF, gazette order, recruitment notice.
   - **Tier 2 (Other Official Government)**: Ministries, departments, statutory bodies, government portals.
   - **Tier 3 (Reputable Secondary)**: Established newspapers, educational publications (context only; cannot override Tier 1).
   - **Tier 4 (Blogs / Coaching / Social Media)**: Prohibited as authoritative evidence; discovery leads only.
3. **Official URL & Provenance Rules**: Absolute HTTP/HTTPS URLs required for real official domains; zero synthetic/fabricated deep links; placeholder strings like `"SOURCE_REQUIRED"` are strictly prohibited in URL fields.
4. **Freshness & Current-Cycle Verification**: Active cycle validation, corrigenda tracking, distinguishing confirmed dates from tentative annual calendars.
5. **Conflict Resolution Protocol**: Step-by-step weighing of source authority and freshness to resolve or flag factual discrepancies.
6. **Anti-Lazy-Placeholder Policy**: Placeholders (`TO_BE_ANNOUNCED`, `TBD`) forbidden unless research proves the authority has genuinely not announced the fact yet.
7. **Module-Specific Deep Research Directives**: Target-aware, exam-agnostic directives for all 24 canonical modules (e.g. dynamic pay framework research in `SALARY` without hardcoded 7th CPC assumptions).
8. **Revision & Human-Edit Preservation**: Protects approved content from stylistic churn; addresses reviewer feedback notes explicitly.
9. **Canonical Taxonomy Lock**: Courage owns curriculum taxonomy; external AI cannot create arbitrary subjects or invent topic IDs.
10. **Candidate-Facing Quality Standards**: High-yield, structured, clear, tabular, zero database/admin jargon or promotional fluff.
11. **Mandatory Pre-Output Self-Checklist**: 14-point internal verification checklist (A through N) executed before emitting JSON.
12. **Strict Structured Output Contract**: Pure JSON conforming to `ExamKnowledgeDocumentSpec v1.0.0`.

## 3. Provider-Neutral Workflow & Copy-Paste Mechanism

The system is completely decoupled from any single LLM API provider:
- **Copy Prompt Button**: The admin copies the generated prompt text from `/admin/exams/knowledge` (`PromptViewerPanel`).
- **External AI Execution**: The admin pastes the prompt into ChatGPT (GPT-4o), Claude (Claude 3.5 Sonnet / Opus), Gemini (Gemini 1.5 Pro), Perplexity, or DeepSeek.
- **Import JSON**: The admin pastes the JSON response back into the Import Modal.
- **Idempotency & Deduplication**: The importer computes a SHA-256 hash of the cleaned JSON payload (`source_spec_hash`) to detect and reject duplicate imports cleanly.
