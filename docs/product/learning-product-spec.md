# Learning & Courses Product Specification
**Detailed Product Specification for Curriculum Taxonomy, Content Studio & Lesson Delivery**

---

## 1. Product Goals & Objectives

1. **Structured Learning**: Deliver granular, high-yield lessons structured by canonical Subjects, Topics, Subtopics, and Learning Units.
2. **Pedagogical Diversity**: Support diverse learning formats (Theory Lessons, Step-by-Step Solved Examples, Mnemonic Cards, Formula Reference Sheets).
3. **Interactive Consumption**: Provide candidates with progress tracking, active checkpoints, and formula callouts.
4. **Editorial Efficiency**: Enable academic authors to write in standard Markdown and compile into interactive MDX without manual frontend development.

---

## 2. Functional Capabilities

- **Curriculum Tree Management**: Hierarchical navigation across canonical subjects (Quant, Reasoning, English, GA) and 36+ high-yield topics.
- **Content Studio Editor**: Markdown editor with live side-by-side preview and AST error diagnostics.
- **Lesson Player**: Responsive reader with bookmarking, lesson completion events, and progress persistence.
- **Syllabus Integration**: Seamless deep-linking from Exam Knowledge syllabus trees directly into matching curriculum units.
