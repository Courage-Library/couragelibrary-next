# Candidate Learning Loop Specification
**End-to-End Candidate Learning Cycle: Explore → Learn → Practice → Mock → Analyze → Master**

---

## 1. The 6-Stage Continuous Learning Loop

Courage Library structures candidate preparation into an iterative, data-driven mastery cycle:

```
                  ┌─────────────────────────────────────┐
                  │ 1. EXPLORE & ORIENT (/exams)        │
                  │ Discover Exam, Cycle, Eligibility,  │
                  │ Pattern, Dates, Cutoffs, Syllabus   │
                  └──────────────────┬──────────────────┘
                                     │
                                     ▼
                  ┌─────────────────────────────────────┐
                  │ 2. LEARN CONCEPTS (/courses)        │
                  │ Study Pedagogical Units, Theory,    │
                  │ Solved Examples, Formula Sheets     │
                  └──────────────────┬──────────────────┘
                                     │
                                     ▼
                  ┌─────────────────────────────────────┐
                  │ 3. TARGETED PRACTICE (/practice)    │
                  │ Daily Topic Drills, Speed Quizzes,  │
                  │ Active Checkpoint Questions         │
                  └──────────────────┬──────────────────┘
                                     │
                                     ▼
                  ┌─────────────────────────────────────┐
                  │ 4. SIMULATE & BENCHMARK (/mock-tests│
                  │ Sectional Mocks, Full-Length Tests, │
                  │ Live All-India National Contests    │
                  └──────────────────┬──────────────────┘
                                     │
                                     ▼
                  ┌─────────────────────────────────────┐
                  │ 5. DIAGNOSE ERRORS (/mistakes)      │
                  │ Mistake Vault Ingestion, Cognitive  │
                  │ Taxonomy Classification, Analytics  │
                  └──────────────────┬──────────────────┘
                                     │
                                     ▼
                  ┌─────────────────────────────────────┐
                  │ 6. RELAPSE DRILLS & MASTERY         │
                  │ Spaced-Repetition Drills, Relapse   │
                  │ Elimination, Verified Mastery State │
                  └──────────────────┬──────────────────┘
                                     │
                                     └─────► (Repeat Loop for Next Topic)
```

---

## 2. Transition Mechanics & Cross-Subsystem Handshakes

1. **Orientation $\rightarrow$ Learning**: Candidate viewing Exam Knowledge syllabus tree clicks topic $\rightarrow$ routes directly to `/courses/[slug]/learn`.
2. **Learning $\rightarrow$ Practice**: Completing a learning unit triggers an active checkpoint drill from the Question Bank.
3. **Practice $\rightarrow$ Assessment**: Topic-level mastery unlocks full-length mock simulations under authentic timer rules.
4. **Assessment $\rightarrow$ Mistake Ingestion**: Submitting a mock automatically captures all incorrect/unattempted responses into the candidate's Mistake Vault.
5. **Mistake Vault $\rightarrow$ Mastery**: Candidate completes spaced-repetition drills until relapse probability drops to zero.
